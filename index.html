Abyss — Jam Delivery Plan

Fast-paced multi-team FPS built in Unity with Netcode for GameObjects

Game Pillars

Relentless Combat

Instant respawns and compact arenas keep squads locked in a kinetic tug-of-war for map control.

Risk-Reward Loadouts

Each gear pick trades survivability, mobility, or DPS for windows of tactical dominance.

Jam-Friendly Netcode

Authoritative server handles score, damage, and spawns. Clients predict movement to stay snappy.

Core Systems Snapshot

Gear Framework

  • ScriptableObject GearDefinition with positive & trade-off modifiers, cooldown, and optional ability prefab.
  • GearRuntimeController aggregates stat deltas, syncs cooldowns via RPCs, spawns Netcode-driven ability prefabs.
  • Flagship gear at launch: Turbo Boots, Enchanted Armor Amulet, Quantum Boots, Self-Destruct Chestplate, Phase Shift Cloak, Grav Anchor, Nano Stim Injector.

Weapons & Attachments

  • WeaponDefinition defines archetype (AR/Sniper/Shotgun/SMG) with base stats.
  • AttachmentDefinition slots (scope, barrel, mag, stock, grip) apply stat offsets + trade-offs.
  • WeaponRuntimeController runs client-side input, server-authoritative hitscan, updates spread/ROF via attachment modifiers.

Match Flow

  • DeathmatchManager balances team assignments (4/5/8 teams), tracks scores, and signals end-of-round.
  • PlayerSpawnManager rotates team spawn anchors, prevents camp loops, integrates with per-team rally zones.
  • Stretch goal: CaptureTheFlagManager reuses team config pipeline, adds flag state sync.

Networking Architecture

  • Unity 2022 LTS + Netcode for GameObjects + Unity Transport (Relay-ready).
  • Authoritative host: server owns damage, score, gear activation. Clients send input commands with reconciliation.
  • Prefabs & ownership: PlayerAvatar, GearAbility, Projectile/HitScanRequest, ScoreManager UI.
  • Bandwidth budget: 30Hz transform sync with delta compression; ability triggers propagate via client RPC hooks.
24-hour team focus
  • Two programmers split Gameplay vs Networking.
  • UI/UX designer owns loadout UI, HUD readability, and quick map paint-overs.
  • Scope wedges: cut CTF or excess gear if stability drops below 8-player target.

Risk Mitigation

  • Netcode Instability: Lock tick rate, enforce authoritative damage, aggressively log de-syncs, keep rollback scope tiny.
  • Gear Balance Chaos: Telemetry hooks track deaths per gear combo; provide emergency switch to disable problem gear.
  • Scope Creep: Maintain cut list (CTF, cosmetics, PvE). If milestones slip, revert to 4-team only and limit gear to 4 items.
  • New Technology: Pair-program first Netcode prefabs, lean on NGO samples, avoid custom transports.
